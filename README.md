# Bluff & Command
1. `npm run install:all`
2. `npm run dev`  -> client http://localhost:3000, server :4000
Open in 2+ browser tabs (each tab needs its own localStorage: use an incognito window for the 2nd player). Create a room, share the code, play 5 rounds.
Deploy: server (Railway/Render, `npm start`), client (Vercel, set NEXT_PUBLIC_SOCKET_URL).
